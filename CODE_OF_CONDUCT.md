# Code of Conduct

## Our commitment

Open Extensions is a technical project intended to be welcoming to contributors with different experience levels and backgrounds. Participants are expected to act respectfully and constructively.

## Expected behavior

- Be respectful, patient, and specific.
- Critique technical decisions and evidence, not people.
- Accept good-faith corrections and explain disagreements without insults.
- Respect privacy; do not publish another person's private information without permission.
- Focus feedback on improving safety, interoperability, documentation, and implementation quality.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized attention, doxxing, deliberate intimidation, and sustained disruptive conduct are not acceptable. Publishing private information, credentials, or unreviewed security vulnerabilities in public issues is also unacceptable.

## Enforcement

Project maintainers may edit or remove contributions and may temporarily or permanently restrict participation for behavior that violates this policy. Report a concern privately to the repository owner or maintainers using GitHub's private contact/reporting channels. Include links or context where possible; do not post sensitive details in a public issue.

Maintainers should respond proportionately, fairly, and with discretion. This policy applies to project spaces, including issues, pull requests, discussions, and project-related community spaces.
