# open-extensions-stepx

Structured instruction documents with exact decimal scaling (.stepx) for the Open Extensions file-format family

This is one distribution of the Open Extensions SDK family. Every
distribution contributes to the shared `open_extensions` namespace package, so
they can be installed together or on their own.

```bash
pip install open-extensions-stepx
```

See the [repository](https://github.com/Kernlab-001/open-extensions) for the
specifications, the other distributions, and the full documentation.
